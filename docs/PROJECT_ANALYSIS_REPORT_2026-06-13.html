Architecture summary

The project has a Python/GitHub Actions scrape plane and an Android Compose presentation plane. GitHub Pages hosts static JSON. The Android app fetches that JSON with OkHttp, validates it, enforces an outbound host allowlist, and can call a Cloudflare Worker to trigger fresh scrapes without shipping a GitHub PAT.

Strengths

  • Zero-cost static hosting and public-data architecture.
  • Good privacy posture: no account, no analytics, no personal data.
  • Scoped GitHub Actions permissions and pinned actions.
  • Dedicated debug APK build workflow now works.
  • FreshnessBanner directly addresses stale-rate user risk.
