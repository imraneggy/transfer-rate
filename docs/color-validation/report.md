# Colour palette validation
Programmatic APCA contrast scoring + visual swatches for every text-on-background pair the Transfer Rate app renders. Generated by `tools/validate_color_palette.py`.
**APCA thresholds**

| Size class       | min |Lc| |
|------------------|---------|
| Headline (24sp+) | 45      |
| Body (14-18sp)   | 60      |
| Small (10-13sp)  | 75      |
