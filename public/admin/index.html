How this works

When you click Save, this page commits a new data/manual-rates.json to the repo via GitHub's Contents API. The next scheduled cron run reads the file and replaces matching "investigating" stubs in public/rates.json with status "manual". The Android app shows manual rates with a MANUAL badge so users know it's an operator-entered value.

To trigger a refresh immediately rather than waiting for the cron: visit Actions → "scrape" workflow → Run workflow.
